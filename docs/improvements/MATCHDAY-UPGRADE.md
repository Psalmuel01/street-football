# Matchday upgrade checklist

Goal: a more responsive, polished football game with grounded movement, real crowd reactions and reasons to return. PES is a reference for responsiveness and presentation, not a claim of equivalent production quality.

- [ ] Movement: momentum through cuts, softer action braking, speed-matched gait and body balance.
- [ ] Ball feel: controlled close touches, longer sprint touches, directional first touch.
- [ ] Audio: silence spoken commentary; licensed recorded applause, cheering and gasp; no reactions after pause/exit.
- [ ] Grounds: three selectable venues with distinct pitch colours and surroundings, independent weather.
- [ ] Return play: saved three-match neighbourhood cup, results and personal bests, restartable season.
- [ ] UI: consistent setup cards, legible match HUD, accessible targets and safe areas, phone/landscape/desktop checks.
- [ ] Verification: gameplay regressions, cup persistence, audio lifecycle, build and browser play checks.

Work on source and local preview first. Keep the submitted Lagos Life listing intact. Release after validation; production rollout is separate from this implementation pass.
